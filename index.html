Author Once, Apply to Many Workflow

1. Select any sprite from the right Sprites Deck by clicking on it to make it active in the canvas.
2. Author animation across frames using deformation tools (Box, Lasso, Puppet Pins, Smear, Pencil, Eraser).
3. Switch between sprites at any time—even mid-animation—by clicking any card on the right.
4. All sprites in the deck share and preview the same motion in real-time.
5. Export individual or batch spritesheets, animated GIFs, or PNG sequences.
